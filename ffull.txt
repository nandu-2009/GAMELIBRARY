#THE DATABASE

conn = get_db_connection()
Opens a connection to your database (likely SQLite).

get_db_connection() is a helper function which returns the users

cursor = conn.cursor()
Creates a cursor object, which is used to execute SQL commands.

INSERT INTO scores(player, wins) → tries to insert a new row into the scores table.
VALUES (?, 1) → inserts the given player name and sets wins = 1.
ON CONFLICT(player) → if a row with the same player already exists (conflict on the player column, which must be a UNIQUE key), then instead of failing:
DO UPDATE SET wins = wins + 1 → increments the existing wins count by 1.

cursor.execute(..., (player,))
Executes the SQL statement, substituting player into the ? placeholder safely (avoids SQL injection).
conn.commit()
Saves the changes to the database.
conn.close()
Closes the connection to free resources.

for key in keys:
    screen.onkeypress(lambda k=key: key_press(k), key)
    screen.onkeyrelease(lambda k=key: key_release(k), key)
Loops through each key in the dictionary.
screen.onkeypress(...) → runs key_press(key) when the key is pressed.
screen.onkeyrelease(...) → runs key_release(key) when the key is released.

Without k=key, all lambdas would capture the last loop value (classic Python closure issue).
With k=key, each lambda remembers its own key correctly.

 lambda function is a small, anonymous function in Python.
Unlike def, it doesn’t need a name.
It’s often used for short, one‑line functions where writing a full def would be overkill.

“Create a default argument i whose value is whatever i was at the time this lambda was defined.”

for i, idx in enumerate(self.sequence):
Loops through the sequence list.
i → the position in the sequence (0, 1, 2, …).
idx → the actual tile/button index to flash.

self.root.after(i * 650, lambda x=idx: self.flash_tile(x))
Schedules a call to self.flash_tile(idx) after a delay.
i * 650 → each tile flashes 650 ms apart, creating a step‑by‑step animation.
lambda x=idx: ... → captures the current idx value (avoids the late binding problem, so each scheduled call remembers its own tile).
self.root.after(len(self.sequence) * 650 + 300, self.enable_input)
After the entire sequence has been flashed, wait a little extra (300 ms).
Then re‑enable input so the player can start reproducing the sequence.
This ensures a smooth transition from “showing” to “listening.
